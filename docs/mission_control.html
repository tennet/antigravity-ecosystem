Pipeline Grafo di Memoria Multi-Tenant

Architettura Laravel 11/12 + MySQL 8.4 InnoDB con protezione dai Gap Lock.

Action Atomica
Modello: MemoryNode

Rappresenta un'entità di conoscenza (`tenant_id`, `name`, `type`, `observations_json`).

UNIQUE (tenant_id, name)
Modello: MemoryRelation

Collega due nodi (`from_node_id`, `to_node_id`, `relation_type`).

CASCADE DELETE su entrambi i nodi
Action: UpsertMemoryNodeAction

Esegue lock deterministico ordinato, retry con exponential backoff + jitter decorrelato.

DB::transaction() anti-deadlock
// backend/app/Actions/UpsertMemoryNodeAction.php
return DB::transaction(function () use ($tenantId, $data) {
  // Lock deterministico sulla riga singola senza toccare gap di intervallo
  $node = MemoryNode::where('tenant_id', $tenantId)
    ->where('name', $data['name'])
    ->lockForUpdate()
    ->first();
  // Esecuzione upsert atomico sicuro
});

Sincronizzazione Simmetrica Multi-Device

Allineamento automatico tra macOS (3 nodi) e Windows 11 (1 nodo) con Google Drive.

Cross-Platform
🍎 macOS (Apple Silicon & Intel)

Script `scripts/sync.sh` compatibile con Zsh e POSIX. Gestisce lockfile per prevenire esecuzioni concorrenti, sync Git e consolidamento Python.

🪟 Windows 11 (PowerShell 7+)

Script `scripts/sync.ps1` con Mutex globale nativo di sistema .NET, risoluzione polimorfica di `python` o `py -3` e allineamento Git simmetrico.
