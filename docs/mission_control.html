Governance v4.1.0: Tie-Breaking Quorum & 4 Bonifiche Formali

Regole operative del Canone Vol. 09 adottate dalla baseline v4.1.0 (nessuna telemetria fake).

L-01 • Outbox Pattern Vol. 01

Divieto di Dual-Write: eventi salvati nella stessa DB::transaction e letti con FOR UPDATE SKIP LOCKED.

L-02 • Quorum 3 Round Vol. 09

Max 3 round dialettici. Prevale @geohot su sicurezza/dati, @carmack su runtime/limiti, @turing sui contratti.

L-03 • Online DDL & SIGHUP Vol. 02/03

Migrazioni MySQL ALGORITHM=INPLACE, LOCK=NONE (lock_wait_timeout=5) + rotazione segreti a caldo via SIGHUP.

L-04 • Doctest & Sunset Vol. 08

Snippet documentati testabili (Doctest) e dismissione API a 3 stadi: DEPRECATED ➔ SUNSET ➔ REMOVED.

Pipeline Grafo di Memoria Multi-Tenant

Architettura Laravel 11–13 (PHP 8.4 Property Hooks) + MySQL 8.4 InnoDB anti-Gap Lock.

Action Atomica
Modello: MemoryNode

Attributi reali: uuid, tenant_id, entity_type, label, properties, vector_embedding, checksum_sha256.

UNIQUE (tenant_id, checksum_sha256)
Modello: MemoryRelation

Collega nodi tramite tenant_id, source_node_id, target_node_id, relation_type, weight.

booted(): anti-self-cycle & targetNode.tenant_id BOLA guard
Action: UpsertMemoryNodeAction

1) SELECT non bloccante per (tenant_id, checksum_sha256); 2) se esiste: lockForUpdate() su Primary Key (id); 3) altrimenti INSERT diretto.

Catch SQLSTATE 23000 / 1062 + Full-Jitter Retry (base 15ms, cap 250ms ➔ 0..250ms, max 5)
Validazione Boundary (StoreMemoryNodeRequest)

Accetta profondità JSON fino al livello 5 (MAX_PROPERTIES_DEPTH = 5, rifiuta livello 6 con HTTP 422), stringhe fino a 10 KB (MAX_PROPERTY_STRING_BYTES = 10240), massimo 500 chiavi in properties e array vector_embedding esclusivamente finiti (blocco IEEE 754 NaN / INF).

Stack Docker Multi-Arch di Produzione

Configurato da Linus Torvalds per macOS (Apple Silicon ARM64) e Windows 11 (AMD64).

Hardened
laravel_mysql Port 3306

MySQL 8.4 LTS con volume persistente mysql_data e infrastructure/mysql/my.cnf ottimizzato per buffer pool InnoDB.

laravel_php Port 9000

PHP 8.4-FPM multi-stage, multi-arch con su-exec e utente non-root appuser (UID 10001).

laravel_nginx Port 8080:80

Webroot confinata esclusivamente a /public sulla porta mappata 8080:80, negazione accesso a file dot (.env, .git).

mission_control Port 8787

Server Node Live SSE read-only (server/mission_control_server.mjs), auth Bearer/HttpOnly su LAN, telemetria Antigravity + Stanza Fenice.

Sincronizzazione Multi-Device

Allineamento di hooks/, memoria e template .env.example tra macOS e Windows 11 (agenti/skill via kit portable/).

Cross-Platform
macOS / Linux (Bash)

Script scripts/sync.sh (bash con BASH_SOURCE): backup atomico di ~/.gemini, symlink di hooks/, link .env.example e lancio unify_memory.py (agenti/skill in portable/; senza lockfile/pull Git).

Windows 11 (PowerShell 7+)

Script scripts/sync.ps1 (con mutex Global\Antigravity_DevOps_Sync_Lock): backup, junction hooks/, .env.example e memoria via pwsh -File (zero override di policy).
